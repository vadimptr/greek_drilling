# Greek Drilling — разделы «Грамматика» и «Мок-тест A1»

Дата: 2026-09-09. Дополняет `2026-09-09-greek-drilling-design.md`.

## Цель

Три раздела в одном приложении: Слова (уже есть), Грамматика (уроки A1 с
упражнениями), Тест (мок-экзамен по образцу Ελληνομάθεια A1, часть «чтение»
плюс грамматика/лексика). Очки и лучший стрик у каждого раздела свои.

## Источник формата экзамена

Экзамен Минобразования Кипра для ВНЖ/гражданства проверяет только «реалии
Кипра»; знание греческого подтверждается экзаменом Ελληνομάθεια (ΚΕΓ),
который проводится на Кипре. Официальная структура A1 (документ
`a1.pdf` ΚΕΓ, «Δομή εξεταστικών δοκιμασιών»):

Κατανόηση γραπτού λόγου — 25 μονάδες, 30 λεπτά:
1. Σωστό-Λάθος: 7 утверждений + пример (7 баллов), текст ~120 слов.
2. Αντιστοίχιση: 6 верных соответствий + пример + 2 лишних варианта (6 баллов), текст ~90 слов.
3. Πολλαπλή επιλογή, 3 варианта: 4 вопроса + пример (6 баллов), текст ~90 слов.
4. Συμπλήρωση κενών: 4 пропуска + пример + 2 лишних варианта (6 баллов), текст ~90 слов.

Проходной порог: не меньше 60% по каждой части; провал в одной части —
провал экзамена (οδηγός εξετάσεων 2022, с. 22).

## Навигация и состояние

- Нижняя панель вкладок: Слова · Грамматика · Тест. Активная вкладка
  сохраняется.
- Шапка общая по форме, но показывает очки и стрик текущего раздела.
- Настройки (шестерёнка) глобальные: направление и автоозвучка (слова),
  кнопка «Сбросить прогресс» сбрасывает все разделы.
- localStorage ключ `greek_drilling.v2`:

```ts
interface AppState {
  version: 2
  tab: 'words' | 'grammar' | 'mock'
  words: RoundState          // как раньше
  grammar: GrammarState
  mock: MockState
}
```

Миграция: если v2 нет, а `greek_drilling.v1` есть — words берётся из v1,
остальное начальное. Невалидный JSON — начальное состояние.

## Грамматика

### Данные

```ts
interface GrammarQuestion {
  id: string          // `${lessonId}-${n}`
  prompt: string      // предложение с ___ или вопрос
  options: string[]   // 3–4 варианта
  answer: number      // индекс правильного
  explain?: string    // пояснение по-русски, показывается при ошибке
}

type LessonSection =
  | { type: 'text'; text: string }
  | { type: 'table'; header: string[]; rows: string[][] }
  | { type: 'examples'; items: { el: string; ru: string }[] }
  | { type: 'note'; text: string }

interface Lesson {
  id: number          // 1..N, порядок = сложность
  title: string
  summary: string
  sections: LessonSection[]
  questions: GrammarQuestion[]   // 10–14
}
```

Список уроков (порядок, ~30): алфавит и ударение; артикли и род;
существительные м. р. (-ος, -ας, -ης) ед. ч.; ж. р. (-α, -η); ср. р. (-ο, -ι,
-μα); множественное число; винительный падеж и артикль (τον/την/το);
родительный (του/της, притяжание); прилагательные -ος/-η/-ο и согласование;
личные местоимения (именительный); είμαι; έχω; настоящее время глаголов на
-ω (тип А); глаголы -άω/-ώ (тип Б1); глаголы -ώ/-είς (тип Б2); глаголы на
-μαι/-άμαι; отрицание δεν/μην и вопросы; вопросительные слова; числительные
1–100 и род (ένας/μία/ένα, τρεις/τρία); время и даты; предлоги σε/από/με/για
и слитные στον/στη/στο; указательные αυτός/εκείνος; притяжательные
местоимения (μου, σου...); безударные местоимения-дополнения (με, σε, τον,
την, το); μου αρέσει / μ' αρέσουν; θέλω να / μπορώ να / πρέπει να; будущее
θα + наст.; аорист частых глаголов (είχα, ήμουν, πήγα, έφαγα, ήπια...);
повелительное наклонение частых глаголов; сравнение πιο ... από; наречия
места и времени.

### Логика (`src/logic/lesson.ts`)

```ts
interface GrammarState {
  completed: number[]
  score: number
  bestStreak: number
  active: { lessonId: number; queue: string[] } | null
}
```

- `startLesson(state, lesson, rng)`: `active = { lessonId, queue: shuffle(ids) }`.
- Текущий вопрос — `queue[0]`.
- `answerLesson(state, correct)`: верно — `score+1`, стрик, вопрос убирается
  из очереди; неверно — `score=0`, вопрос переносится в конец очереди (если он
  один — остаётся). Пустая очередь — урок в `completed`, `active=null`.
- `abandonLesson(state)`: `active=null` (прогресс урока не сохраняется).
- Урок можно проходить повторно; `completed` не убывает.

### UI

- Список уроков: «Пройдено N из 30», карточки с номером, названием, галочкой.
- Экран урока: объяснение (текст, таблицы, примеры с кнопкой 🔊), кнопка
  «К упражнениям». Кнопка «Правило» во время упражнений открывает объяснение
  шторкой.
- Упражнение: предложение с пропуском крупно, 3–4 кнопки как в словах; те же
  анимации; при ошибке под кнопками пояснение `explain`, переход по тапу
  «Дальше». Прогресс «осталось K».
- Завершение: «Урок пройден», кнопки «Следующий урок» и «К списку».

## Мок-тест

### Данные

```ts
interface TrueFalseTask { type: 'tf'; title: string; intro: string; text: string; items: { statement: string; answer: boolean }[] }        // 7
interface MatchTask     { type: 'match'; title: string; intro: string; text: string; lefts: string[]; rights: string[]; answer: number[] }  // 6 lefts, 8 rights
interface ChoiceTask    { type: 'mc'; title: string; intro: string; text: string; items: { question: string; options: string[]; answer: number }[] } // 4×3
interface GapTask       { type: 'gap'; title: string; intro: string; text: string; bank: string[]; answer: number[] }  // text с {{1}}..{{4}}, bank 6
type ReadingTask = TrueFalseTask | MatchTask | ChoiceTask | GapTask
interface LanguageItem  { prompt: string; options: string[]; answer: number; kind: 'grammar' | 'vocab' }  // 3 варианта
interface MockVariant   { id: number; title: string; reading: [TrueFalseTask, MatchTask, ChoiceTask, GapTask]; language: LanguageItem[] } // 25
```

Вариантов минимум 3. Часть А ровно повторяет официальную структуру
(без примера-«0», картинки заменены словами/фразами в банке). Часть Б —
25 вопросов (примерно 15 грамматика, 10 лексика), 3 варианта ответа.

### Логика (`src/logic/mock.ts`)

- Ответы: `ReadingAnswers = (number | null)[][]` по заданиям (tf: 1/0),
  `LanguageAnswers = (number | null)[]`.
- `gradeReading(variant, answers)` → `{ perTask: number[]; total: number; max: 25 }`.
- `gradeLanguage(variant, answers)` → `{ total: number; max: 25 }`.
- `isPassed(total, max)` → `total / max >= 0.6`; экзамен сдан, если сданы обе части.
- `MockState = { history: MockAttempt[]; nextVariant: number }`,
  `MockAttempt = { date: string; variantId: number; reading: number; language: number; passed: boolean }`.
- Прохождение теста хранится только в памяти страницы (перезагрузка =
  начать заново).

### UI

- Старт: описание формата и порога, лучший результат, история последних
  попыток, кнопка «Начать вариант N».
- Часть А: по одному заданию на экран, текст сверху (сворачиваемый), ниже
  элементы: tf — две кнопки «Σωστό/Λάθος»; match — `<select>` у каждой левой
  фразы; mc — 3 кнопки-радио; gap — `<select>` внутри текста на месте
  пропуска. Кнопки «Назад/Дальше», индикатор «Задание 2 из 4», таймер 30:00
  сверху; по нулю — автопереход к части Б.
- Часть Б: вопросы списком по одному на экран или прокруткой (один экран с
  прокруткой, 25 карточек с 3 кнопками). Таймер 20:00.
- Результат: баллы по частям, «Сдано/Не сдано» по каждой и итог, разбор:
  каждое задание с отметкой верно/неверно и правильным ответом. Кнопка
  «Ещё раз» (следующий вариант).

## Тесты

- `lesson.test.ts`: очередь, перенос неверного в конец, завершение, очки.
- `mock.test.ts`: подсчёт по каждому типу, порог 60%, null-ответы.
- `storage.test.ts`: v2 сериализация, миграция с v1, невалидные данные.
- `data/grammar.test.ts`: id уникальны и последовательны, `answer` в диапазоне,
  ровно один `___` в prompt для вопросов с пропуском, 10–14 вопросов на урок,
  30+ уроков.
- `data/mock.test.ts`: у каждого варианта 4 задания нужных типов, 7/6/4/4
  пунктов, `rights` = 8, `bank` = 6, в тексте gap ровно 4 плейсхолдера,
  language = 25, индексы в диапазоне, варианты ответов уникальны.
