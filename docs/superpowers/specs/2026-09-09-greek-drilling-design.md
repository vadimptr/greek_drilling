# Greek Drilling — дизайн

Дата: 2026-09-09

## Цель

Мобильный сайт для заучивания базовой лексики греческого языка уровня A1
(600–800 слов). Пользователь видит слово и выбирает из четырёх вариантов
перевода. Неверно отвеченные слова повторяются чаще, пока не будут отвечены
верно три раза. Один пользователь, один телефон (iPhone), прогресс хранится
в браузере.

## Стек и структура

- Vite + React 18 + TypeScript (strict), как в `rust_calculator`.
- Тесты: Vitest.
- Без бэкенда. Статика раздаётся `nginx:alpine`.
- Структура `src/`:
  - `data/words.ts` — словарь.
  - `logic/` — чистые функции без React: выбор слова, обновление состояния,
    дистракторы, сериализация. Покрыты тестами.
  - `components/` — экранные компоненты.
  - `App.tsx` — связывает логику, состояние и localStorage.

## Словарь

Файл `src/data/words.ts` экспортирует массив `Word`:

```ts
type Pos = 'noun' | 'verb' | 'adj' | 'adv' | 'pron' | 'prep' | 'conj' | 'num' | 'phrase' | 'other'

interface Word {
  id: number        // стабильный, уникальный; используется в localStorage
  el: string        // греческое слово; существительные с артиклем: «το σπίτι»
  ru: string        // русский перевод, одно короткое значение
  pos: Pos
  topic: string     // тема: greetings, numbers, time, family, food, home, city, ...
}
```

Объём: 650–750 слов. Темы: приветствия и вежливость, числа, время и дни,
семья и люди, еда и напитки, дом и быт, город и места, транспорт и
путешествия, тело и здоровье, одежда, погода и природа, цвета, работа и
учёба, базовые глаголы, прилагательные, наречия, местоимения, предлоги,
союзы и частицы, вопросительные слова, частые фразы.

Список составляется вручную на основе типовых учебных списков A1
(Ελληνικά Α, Κλικ στα ελληνικά, частотные списки). Тест проверяет:
нет дублей `id`, нет дублей `el`, нет дублей `ru`, все поля непустые,
размер в диапазоне 600–800.

## Логика повторения

Состояние раунда (`RoundState`):

```ts
interface RoundState {
  learned: number[]              // id слов, выученных в текущем раунде
  weak: Record<number, number>   // id → сколько верных ответов ещё нужно (начинается с 3)
  score: number                  // текущий стрик очков
  bestStreak: number             // максимальный стрик за раунд
  lastId: number | null          // последнее показанное слово
  direction: 'el-ru' | 'ru-el'
}
```

Правила:

- **Следующее слово.** Кандидаты «новые» = все слова, кроме `learned` и
  ключей `weak`. Если `weak` не пуст и (новых нет или случайное число < 0.7),
  берём случайное слово из `weak`; иначе случайное из новых. Если у выбранного
  пула больше одного слова, `lastId` исключается.
- **Верный ответ.** `score += 1`, `bestStreak = max(bestStreak, score)`.
  Если слово в `weak`: счётчик уменьшается; при достижении 0 слово удаляется
  из `weak` и добавляется в `learned`. Если слово не в `weak`: добавляется
  в `learned`.
- **Неверный ответ.** `score = 0`. Слово помещается в `weak` со счётчиком 3
  (даже если уже было там с меньшим счётчиком) и удаляется из `learned`.
- **Победа.** `learned.length === words.length` и `weak` пуст. Показывается
  экран победы. «Начать снова» возвращает начальное состояние
  (`learned = []`, `weak = {}`, `score = 0`, `bestStreak = 0`), направление
  сохраняется.
- **Дистракторы.** Три слова, отличных от целевого, с переводами (в текущем
  направлении), не совпадающими между собой и с правильным. Приоритет словам
  той же части речи; если их меньше трёх, добираем из остальных. Четыре
  варианта перемешиваются.
- **Случайность** передаётся функцией `rng: () => number`, чтобы тесты были
  детерминированными.

## Направление

Тумблер в настройках: «греческий → русский» (по умолчанию) и
«русский → греческий». Меняет только то, что показано по центру и в кнопках.
Прогресс общий.

## Хранение

Ключ `greek_drilling.v1` в localStorage, JSON `RoundState`. Загрузка при
старте с валидацией: при ошибке разбора или несовпадении формы — начальное
состояние. Сохранение после каждого ответа и смены настроек. Id слов,
отсутствующих в словаре (после обновления списка), отбрасываются при загрузке.

## UI

Один экран, высота `100dvh`, отступы под safe-area (`env(safe-area-inset-*)`),
`viewport-fit=cover`. Шрифт системный.

- **Шапка.** Слева очки («⚡ 12»), справа лучший стрик («🏆 27»), кнопка
  шестерёнки. Под шапкой тонкая полоса прогресса и подпись «Выучено 123 / 700 ·
  слабых 8».
- **Центр.** Целевое слово крупно (clamp 32–44px), под ним мелко часть речи.
- **Низ.** Четыре кнопки на всю ширину, высота не меньше 56px, крупный
  текст, скругление.
- **Верный ответ.** Кнопка становится зелёной с коротким пульсом; через ~500мс
  следующее слово. Очки в шапке подпрыгивают.
- **Неверный ответ.** Нажатая кнопка красная с тряской, правильная
  подсвечивается зелёным; переход через ~1100мс. Очки в шапке сбрасываются.
- Во время анимации остальные кнопки не реагируют.
- **Настройки.** Шторка снизу: тумблер направления, кнопка «Сбросить прогресс»
  с подтверждением.
- **Победа.** Полноэкранный оверлей с CSS-конфетти, текст «Все N слов!» (N = размер словаря),
  лучший стрик раунда, кнопка «Начать снова».
- **Тема.** Светлая и тёмная через `prefers-color-scheme`.
- **PWA.** `manifest.webmanifest` (`display: standalone`, иконки), метатеги
  для iOS, чтобы добавить на домашний экран без адресной строки. Без
  service worker.

## Деплой

Полностью повторяет `rust_calculator`, порт снаружи **9093**.

- `Dockerfile`: `node:20-alpine` сборка → `nginx:alpine`, `nginx.conf` с
  `try_files ... /index.html`.
- `docker-compose.yml`: образ `ghcr.io/vadimptr/greek_drilling/app:latest`,
  `9093:80`, `restart: unless-stopped`. Копируется на мак в
  `/Users/admin/workdir/greek_drilling/`.
- `.github/workflows/main.yml`:
  1. `build`: checkout → `npm ci` → `npm test` → `docker build` →
     push в ghcr (логин по `GITHUB_TOKEN`, `permissions: packages: write`).
  2. `deploy` (needs build, `permissions: packages: read`): ssh на мак
     (`appleboy/ssh-action`), скрипт:
     `export PATH=$PATH:/usr/local/bin`; `security unlock-keychain`;
     `open -a Docker`; ожидание `docker info` до 120 с; `cd WORK_DIR/greek_drilling`;
     `docker login ghcr.io` с `GITHUB_TOKEN` джоба; `docker compose pull`;
     `docker compose up -d`.
- Переменные репозитория: `SSH_HOST=vadimptr.ddns.net`, `SSH_PORT=2022`,
  `WORK_DIR=/Users/admin/workdir`. Секреты: `SSH_USER`, `SSH_PASSWORD`,
  `SSH_PRIVATE_KEY` (ключ `~/.ssh/github_actions_rust`, он уже в
  `authorized_keys` на маке). `CR_PAT` не нужен.
- Результат: `http://vadimptr.ddns.net:9093`.

## Тесты

- `logic/*.test.ts`: выбор следующего слова (пул слабых/новых, исключение
  `lastId`, поведение при пустых пулах), верный/неверный ответ, вычёркивание
  после трёх верных, сброс счётчика при повторной ошибке, победа, дистракторы
  (уникальность, приоритет части речи, добор), сериализация и валидация
  localStorage.
- `data/words.test.ts`: проверки словаря.
- `tsc` в `npm run build`; `npm test` в CI перед сборкой образа.

## Вне объёма

Аккаунты, синхронизация между устройствами, звук, статистика по дням,
обратный ввод слова с клавиатуры.
