# Раздел «Речь»: произношение слов с распознаванием — дизайн

Дата: 2026-09-10. Статус: согласован с пользователем (вкладка отдельная, подсказка переключается,
пропуск без штрафа, распознавание на сервере whisper.cpp, без привязки к Web Speech API iOS).

## Цель

Четвёртая вкладка «Речь»: те же 743 слова, но пользователь произносит слово вслух. Приложение записывает
звук, отправляет на домашний сервер, whisper.cpp распознаёт, ответ сравнивается с целевым словом.
Верно — +1 очко, анимация, следующее слово. Неверно — очки в 0, слово в слабые (3 верных ответа до
«выучено»), анимация ошибки, показывается, что услышано. Кнопка «Пропустить» — без штрафа.
Очки, лучший стрик, выученные и слабые у раздела свои. Победа и рестарт как в «Словах».

Работает в любом браузере с микрофоном (Safari iOS, в т.ч. с домашнего экрана, Chrome Android/desktop),
потому что на клиенте только запись, распознавание на сервере. Требует HTTPS — есть
(https://languagedrilling.com).

## Не делаем

Оценку качества произношения (только «слово совпало / нет»), оффлайн-режим, распознавание фраз
длиннее ~4 секунд, запись через MediaRecorder (кодеки различаются по браузерам).

## Архитектура

```
Браузер                                   Домашний мак (docker, сеть infra)
getUserMedia → AudioContext → PCM 16 kHz  ──POST /api/transcribe (WAV)──► nginx (app) ──► whisper:8080/inference
← {text}                                                                   ◄────────────── whisper-server (ggml-small, -l el)
matchesWord(text, word) → верно/неверно
```

- **Запись** (`src/logic/recorder.ts`): `getUserMedia({audio})`, `AudioContext`, ScriptProcessorNode
  (работает везде, в т.ч. iOS) собирает Float32 → ресемплинг до 16 kHz → WAV PCM16 mono
  (`src/logic/wav.ts`). Остановка: по тишине (RMS ниже порога 700 мс после того, как речь была) или
  по максимуму 4 с. Если речи не было вовсе (RMS никогда не превысил порог) — на сервер не шлём,
  показываем «Не расслышал».
- **Транспорт** (`src/logic/transcribe.ts`): `POST /api/transcribe`, multipart: `file` (wav),
  `response_format=json`, `temperature=0`, `language=el`. Ответ `{text}`. Ошибки: сеть/5xx →
  `TranscribeError('unavailable')`, показываем «Сервер распознавания недоступен», без штрафа.
- **Сравнение** (`src/logic/match.ts`), чистая функция `matchesWord(heard, word)`:
  нормализация обеих строк — нижний регистр, снятие ударений/диерезиса (NFD, убрать U+0300–036F),
  ς→σ, убрать знаки препинания, схлопнуть пробелы; у целевого слова отбрасывается ведущий артикль
  (ο/η/το/οι/τα), у услышанного — тоже; совпадение полное либо расстояние Левенштейна ≤ 1 при длине
  цели ≥ 5 и ≤ 2 при ≥ 9 (без учёта пробелов); для `pos: 'num'` дополнительно принимается цифровая
  запись (таблица числительных → число, `μισός` → «½»/«0.5» не нужно, только целые).
  Также принимается, если услышанная строка содержит цель как отдельное слово (whisper иногда
  дописывает «Ναι.» или артикль) — только когда цель одно слово и длиннее 3 букв.
- **Состояние** (`src/logic/speakState.ts`): `SpeakState {learned, weak, score, bestStreak, lastId}`.
  Общие функции `applyAnswer`, `isWin`, `pickNext` обобщаются на интерфейс `Progress` (RoundState его
  расширяет), чтобы не дублировать. `skipWord(state, id)` — только `lastId`. `restartSpeak`.
- **Настройка подсказки** `speakHint: 'el' | 'ru'` в AppState (глобальные настройки):
  `el` — греческое слово + транскрипция + перевод; `ru` — только перевод.
- **AppState v3**: `{version: 3, tab, words, grammar, mock, speak, speakHint}`; ключ
  `greek_drilling.v3`, миграция с v2 (и v1 через существующий путь): speak = начальное, speakHint='el'.
  `Tab` получает 'speak'. Сброс прогресса сбрасывает и speak, сохраняет speakHint.

## UI (`src/screens/SpeakScreen.tsx`)

Экран как в «Словах»: сверху карточка слова (в режиме `el` — слово по-гречески, транскрипция, перевод
серым; в режиме `ru` — перевод крупно). Тап по слову — карточка сведений (WordInfoPopup).
Ниже статус: «Нажми и скажи», «Слушаю…» с индикатором уровня, «Распознаю…», результат.
Кнопки: большая круглая 🎤 «Сказать» (во время записи — пульсирует, повторный тап = остановить),
🔊 «Послушать» (Web Speech озвучка, как в «Словах»), «Пропустить».
Результат верно: зелёная вспышка карточки, «✓ Верно», через 600 мс следующее слово.
Неверно: тряска, «✗ Услышал: …» красным, правильное слово озвучивается, кнопки «Ещё раз» (повторить то же
слово, микрофон тоже активен) и «Дальше», очки уже 0; верный повтор засчитывается как обычный верный ответ.
Не расслышал/сервер недоступен: нейтральная плашка, без изменений очков, можно повторить.
Микрофон запрещён/недоступен: плашка с объяснением, кнопка «Сказать» неактивна, «Пропустить» работает.
Шапка: ⚡ очки, 🏆 лучший стрик, «Выучено N / 743 · слабых M», прогресс-бар. Победа — WinOverlay.

## Инфраструктура

- `deploy/whisper/`: Dockerfile (сборка whisper.cpp v1.9.3 под arm64, target whisper-server),
  `entrypoint.sh` (скачивает ggml-small в volume при первом старте, запускает сервер `-l el
  --no-timestamps`), compose в сети `infra` (external), порт наружу не публикуется.
- `nginx.conf` приложения: `location = /api/transcribe { proxy_pass http://whisper:8080/inference;
  client_max_body_size 2m; proxy_read_timeout 60s; }`.
- `docker-compose.yml` приложения: сервис подключается к сети `infra` (external) в дополнение к
  дефолтной. Копия compose на маке обновляется вручную (scp), деплой прежний (Actions → pull/up).
- `vite.config.ts`: dev-прокси `/api` → `https://languagedrilling.com` для локальной разработки.

## Тесты

Vitest: `match.test.ts` (нормализация, артикли, опечатки, числа, лишние слова, отрицательные случаи),
`wav.test.ts` (ресемплинг длины/значений, заголовок WAV 44 байта, размеры), `speakState.test.ts`
(skip меняет только lastId; applyAnswer/isWin/pickNext работают со SpeakState), `appState.test.ts`
(v3 сериализация, миграция v2→v3, мусор → начальное, speakHint валидация), `transcribe.test.ts`
(fetch мок: успех, 502 → unavailable, кривой JSON). Ручная проверка: puppeteer с
`--use-fake-device-for-media-stream --use-file-for-fake-audio-capture=<wav>` (WAV сгенерирован
`say -v Melina` и сконвертирован в 16 kHz) против прод-сервера.
